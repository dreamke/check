# check - 出行物品点检清单

> **在线使用：https://dreamke.github.io/check/**
>
> 手机或电脑浏览器打开即用，无需安装、注册和登录。

一个出行物品点检静态网页：出发前列好物品清单，收拾一件勾一件，全部勾完再出门。

## 功能

| 功能 | 说明 |
|---|---|
| 分类管理 | 默认"衣服 / 洗漱 / 随身"三个分类共 24 项，分类可新增、可删除 |
| 物品点检 | 点击方框或物品名称即勾选，勾选后该行文字划线置灰 |
| 进度统计 | 顶部显示总项数、已检项数与百分比进度条，每个分类有独立计数 |
| 物品增删 | 分类底部输入名称回车即添加，每项右侧 × 删除 |
| 标题编辑 | 点击标题直接修改，浏览器标签页标题同步更新 |
| 快捷操作 | "重置全部勾选"保留清单清空勾选，"恢复默认清单"回到初始 24 项 |

## 数据说明

- 点检记录、增删的物品和标题保存在**当前设备的浏览器 localStorage** 中，不上传服务器，关闭页面后再打开仍然保留
- 清除浏览器缓存 / 网站数据、使用无痕模式会导致记录丢失；换设备或换浏览器各自独立记录，互不同步
- 页面公开访问，但数据是本地的，每个人勾选的内容只有自己能看到
- 出发前点检完成时，建议用手机长截图整页保存一份作为备份，也可直接转发给同行的人

## 技术实现

- 单文件 HTML，原生 CSS / JavaScript，无框架、无后端、无数据库
- 托管在 GitHub Pages（`main` 分支根目录直出）
- 修改 `index.html` 后 push 到 `main` 分支即自动重新部署
- 本地使用：下载 `index.html` 双击打开，或 `git clone` 后直接运行，功能完全一致

## 使用方法

1. 浏览器打开 https://dreamke.github.io/check/ （或仓库首页扫码）
2. 按需增删物品和分类，点击标题可修改
3. 收拾一件勾一件，顶部进度条实时更新
4. 返程收拾行李时点"重置全部勾选"，同一份清单再点检一遍
